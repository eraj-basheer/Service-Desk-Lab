# KB-03 - Accessing a shared mailbox

**Status:** ☐ Draft
**Audience:** all staff
**Last reviewed:** 2026-11

## What this fixes

You have been given access to a shared mailbox - such as Accounts Payable or Reception - and it is not appearing, or you need to add it manually.

## Before you start

- Confirmation from the service desk that access has been granted
- Outlook on the desktop, or Outlook on the web

## Steps - Outlook on the web

1. Sign in at `outlook.office.com`.
2. In the left-hand folder pane, scroll to the bottom.
3. The shared mailbox appears as a separate expandable folder. If it does not, refresh the page.

## Steps - Outlook desktop, automatic

1. Close Outlook completely.
2. Reopen Outlook.
3. The mailbox appears in the folder pane within about 30 minutes of access being granted.

Automatic mapping only works when the permission was granted with automapping enabled. If it has been longer than an hour, use the manual steps below.

## Steps - Outlook desktop, manual

1. Open **File → Account Settings → Account Settings**.
2. Select your account and choose **Change**.
3. Choose **More Settings → Advanced → Add**.
4. Type the shared mailbox address, for example `accounts.payable@coveconsult.onmicrosoft.com`.
5. Choose **OK**, then **Next**, then **Finish**.
6. Restart Outlook.

## Sending from the shared mailbox

1. Compose a new email.
2. Choose **From** and select the shared mailbox address.
3. If the address is not listed, choose **From → Other Email Address** and type it.

Sending requires **Send As** permission. If you can see the mailbox but cannot send from it, the service desk needs to add that permission.

## If it still does not work

- Confirm the service desk has granted **Full Access** - viewing and sending are separate permissions.
- Confirm you are using the full address, not the display name.
- Sign out of Outlook on the web and sign back in.
